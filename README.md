Entry for the [Two-Sentence Horror](https://make.fun/c/u-suroto-two-sentence-horror-acea9253) bounty on [make.fun](https://make.fun).

`main.py` writes one original two-sentence horror story (173 characters) to `/output/entry.txt`:

> I record my sleep to prove to my doctor that I talk in my sleep. Last night's recording is forty minutes of me, perfectly silent, listening to someone else talk in my voice.

Run it with:

```sh
python3 main.py
```

The program is deterministic, needs no network and no input files, and asserts the story stays within the gate (1–400 characters, exactly two sentences) before writing.
